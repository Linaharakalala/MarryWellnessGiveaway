# MedicalM

Medical Mary's 7-Day Wellness Reset giveaway landing page.

## Run locally

```bash
npm install
npm run dev
```

## Share publicly

The repository includes a GitHub Pages deployment workflow. After pushing the project to GitHub, enable **Settings → Pages → GitHub Actions** once. The site will then be publicly viewable without visitors signing in:

`https://linaharakalala.github.io/MarryWellnessGiveaway/`

The repository owner must have access to GitHub to publish updates, but viewers do not need GitHub accounts. The form remains a local preview until an approved form provider is connected.
